# 개선 C++ tail 대 Rob 원본 (2026-11-02)

Rob 상주 풀은 제외했다. 새 합법 무작위 큐브 2,000개를 양쪽 모두 1스레드로 3라운드 × 2반복 측정했다. 바이너리는 변경하지 않았으며 한 번에 한 솔버만 실행했다. 라운드별 실행 순서를 바꾸고 동일한 입력 순서와 300개 워밍업을 사용했다.

새 C++은 평균 71.5%, P95 61.0%, P99 49.2% 짧았다. 1975/2,000개 입력에서 더 빨랐다.

극단적으로 느린 일부 입력은 남아 있다. 1ms 초과는 C++ 6개, Rob 2개였고 관측 최대는 C++ 2.2043ms, Rob 1.1540ms였다. 따라서 P99까지의 개선을 모든 입력의 최악 시간 우위로 해석하지 않는다.

시간은 큐브별 반복 중앙값 → 라운드 중앙값으로 요약했다. 초기화·IPC·JSON·독립 재생 검증은 제외한다. Rob 원본은 요청마다 작업 스레드를 생성·종료하며 이 비용이 solve_ns에 포함된다. C++ serial은 호출 스레드에서 직접 실행한다. 전체 요청 지연 비교이고, 거리표 및 순수 탐색만 분리한 비교는 아니다. 각 실험 사이의 절대 시간을 섞지 않았다.

측정 출력 24,000개를 포괄하는 3,999개 고유 입력·해법 쌍을 독립 54스티커 모델에서 재생했다. 모두 유효하고 최대 21 HTM 이하였다. 최단해 보장은 없다.
