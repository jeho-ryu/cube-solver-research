# 학습량 3천·1만·3만 비교: 동일한 4.7KiB DNN

**이번 구조에서는 학습 데이터 증가로 평균 속도나 탐색량이 개선되는 추세를 확인하지 못했습니다.**
3천→1만에서 탐색량은 약 0.60% 줄었지만, 3천→3만에서는 약 0.34% 늘었습니다.
두 비교 모두 95% 구간에 차이 없음이 포함됩니다. 초기값 3개의 평균 풀이 시간은
각각 1.2974ms, 1.2972ms, 1.3059ms로 거의 같았습니다.

원본 min2phase의 평균은 1.2949ms이고, 원본 대비 탐색량은 각각 2.35%, 1.73%, 2.70% 많았습니다.
이전 작은 파일럿에서 관측한 소폭의 탐색량 감소도 이번 새 2천 큐브에서는 재현되지 않았습니다.
신경망 모델을 기존 솔버의 기본 경로로 적용하지 않았습니다.

이 결과만으로 정보 부족·모델 용량·학습 목표 중 무엇이 원인인지 확정할 수는 없습니다.
다만 같은 입력과 구조에서 데이터를 계속 늘리는 방향을 지지하는 증거는 얻지 못했습니다.
다음 연구가 필요하다면 입력 정보 또는 학습 목표를 별도 실험으로 바꾸는 편이 타당하다는 판단입니다.

62→16→8→6, 파라미터 1,198개, 가중치 파일 4,820바이트를 유지했습니다. 학습 데이터만 중첩된 3,000/10,000/30,000개로 늘렸고 각 크기에서 같은 초기값 3개로 학습했습니다.

모든 가중치는 공통 검증 큐브 1,000개로 선택하고 동결했습니다. 새 테스트 2,000개에서 각 방식을 3회 측정했습니다. 아래 DNN 값은 초기값 3개의 평균입니다.

## 바뀌지 않은 조건

- 원래 tiny_tie_lab의 TieSearch/TieNet과 min2phase 원본 파일을 수정하지 않았습니다. 탐색 시작 시 최소 하한 동점 방향 사이에서만 최대 한 번 추론합니다.
- 입력 62개, 은닉층 16/8, 출력 6, FP32, AdamW(lr=.003, weight_decay=.01), batch=256, 100 epoch와 손실 함수를 유지했습니다.
- 100 epoch를 유지했으므로 데이터가 클수록 총 업데이트 횟수도 증가합니다. 같은 업데이트 횟수에서 데이터 다양성만 분리한 실험은 아닙니다.
- 3천 데이터는 이전 실험의 검증된 라벨을 재사용했고, 1만/3만은 이를 포함하는 중첩 집합입니다. 새 라벨과 캐시 해법 모두 독립 큐브로 검증했습니다.
- 검증 1천 개는 새 입력이며 모든 모델에서 공통입니다. 각 모델의 epoch를 검증 총 P1+P2 호출 수로 선택하고, 테스트를 보기 전에 동결했습니다.
- 데이터는 시드가 고정된 무작위 cubie 상태입니다. 학습·검증·테스트·이전 테스트 중복을 배제했습니다.
- 첫 21수 이하 해법 비교입니다. 고정 시간 내 가장 짧은 해법을 찾는 실험이나 최단 해법 증명은 아닙니다.

## 측정·검증

- 시간에 입력 검증·탐색 준비·특징 생성·DNN 추론·탐색·결과 문자열 생성을 포함합니다. JVM 시작·표 생성·가중치 로드·예열·IPC·독립 검증은 제외합니다.
- 모델 9개를 같은 JVM에 미리 로딩한 뒤 방식과 큐브 순서를 섞었습니다. 실제 메모리는 측정하지 않았습니다. 개별 모델 파일 크기는 모두 동일합니다.
- 학습 프로세스 종료 후 측정합니다. 실제 노드 수는 시간 측정 JVM을 닫은 뒤 별도 JVM에서 셉니다.
- 시간 측정 해법 78,000개와 계측 해법 26,000개를 독립 facelet 구현으로 검증했습니다.
- 원본과 control의 해법 및 P1/P2/pre 호출 수가 모두 일치했고, 계측 실행의 해법·선택 방향은 시간 측정의 모든 반복과 일치했습니다.
- 원시 결과·분할 데이터·모델별 학습 이력·소스 및 가중치 해시를 함께 저장합니다. 재실행은 상위 README.md를 참고하세요.
