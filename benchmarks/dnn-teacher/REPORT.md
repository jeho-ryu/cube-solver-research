# min2phase 지도학습 + DNN 빔서치 실험 결과

실행 완료: 2026-09-10T13:58:37.360412+00:00. 로컬 CPU에서 실제로 데이터 생성, 두 모델 학습, 새 큐브 60개 평가를 수행했습니다.

추가 학습 모델은 57/60개, 기존 AlphaCube는 57/60개를 해결했습니다. min2phase 첫 해를 보관하는 정책의 평균은 기존 모델 16.03 HTM, 추가 학습 모델 16.02 HTM입니다.

이번 표본에서는 추가 학습 모델을 사용하는 정책이 기존 모델보다 짧은 평균 해법을 얻었습니다. 작은 단일 실행 결과이며 일반적인 우월성의 증거로 확대할 수 없습니다.

min2phase에 추가 탐색 시간을 준 대조군보다 평균 해법이 짧아지지 않았습니다. 현재 목표인 더 좋은 솔버 달성은 확인되지 않았습니다.

## 동일 조건 실제 탐색

세 DNN 모두 FP32, CPU 4스레드, 빔 폭 1024, 최대 깊이 21, 탐색당 3초입니다. min2phase 추가 탐색에도 3초를 주었습니다. HTM은 180도 회전을 1회로 셉니다.

| 방식 | 해결 | 성공률 | 성공한 입력 평균 HTM | 전체 입력 평균 시간 |
|---|---:|---:|---:|---:|
| min2phase 첫 해 | 60/60 | 100.0% | 18.22 | 0.0009초 |
| min2phase 추가 탐색 | 60/60 | 100.0% | 14.95 | 1.9676초 |
| 기존 AlphaCube | 57/60 | 95.0% | 15.89 | 1.1043초 |
| 기존 모델 + min2phase 추가 학습 | 57/60 | 95.0% | 15.88 | 1.0340초 |
| min2phase 데이터로 처음부터 학습 | 7/60 | 11.7% | 10.86 | 1.3268초 |

**실패한 큐브는 평균 HTM에서 제외됩니다. 해결 대상이 다르므로 이 평균만으로 모델을 비교하면 안 됩니다.** 실패는 CSV에 그대로 남겨두었습니다. 시간은 실패를 포함한 모든 입력의 평균이며 모델 로딩·예열·별도 검증은 제외합니다. 시간 제한은 깊이 경계에서 확인하므로 한 단계만큼 초과할 수 있습니다.

| 비교 모델 | 기존 모델과 모두 성공 | 더 짧음 / 같음 / 더 김 | 기존 모델 평균 HTM | 비교 모델 평균 HTM |

세 DNN이 모두 성공한 입력은 7개입니다. 공통 입력 평균 HTM: 기존 AlphaCube 9.71, 기존 모델 + min2phase 추가 학습 9.71, min2phase 데이터로 처음부터 학습 10.86.

## min2phase 첫 해를 보관했을 때

앞선 실제 측정 해법 중 `min(첫 해, 빔서치 해법)`을 선택한 파생 결과입니다. 빔서치 실패 또는 더 긴 해법이면 첫 해를 반환합니다. 별도로 재실행한 탐색 결과는 아니며 이 정책의 시간은 두 탐색 시간의 합입니다.

| 빔서치 모델 | 전체 입력 평균 HTM | 첫 해보다 개선 | 두 탐색 시간 합의 평균 |
|---|---:|---:|---:|
| 기존 AlphaCube | 16.03 | 32/60 | 1.1052초 |
| 기존 모델 + min2phase 추가 학습 | 16.02 | 31/60 | 1.0349초 |
| min2phase 데이터로 처음부터 학습 | 17.83 | 5/60 | 1.3277초 |

대조군: min2phase 첫 해 18.22 HTM, min2phase 추가 탐색 14.95 HTM.

## 데이터와 학습 확인

| 분할 | 시작 큐브 수 | 원래 상태·행동 수 | 중복/분할 간 겹침 제거 후 |
|---|---:|---:|---:|

시작 큐브 단위로 분할한 뒤 상태 중복을 제거했습니다. 검증·테스트 시작 상태는 앞선 분할의 상태와 겹치지 않습니다. 테스트는 10/20/25회 섞은 입력 각 20개로, 상태 공간 전체에서 균등하게 뽑은 표본은 아닙니다. 기존 AlphaCube 사전학습 데이터의 전체 목록은 없으므로 그 데이터와의 중복 여부는 확인하지 못했습니다.

선생 데이터 생성 시간은 100.4초입니다. 선생 해법마다 추가 탐색 약 0.04초를 허용했습니다. 해법은 유효하지만 최단임을 보장하지 않습니다.

| 모델 | 학습 시간 | 선택 epoch | 학습 전 검증 CE | 선택 검증 CE | 선택 검증 정답률 |
|---|---:|---:|---:|---:|---:|
| 기존 모델 + min2phase 추가 학습 | 73.1초 | 6/6 | 1.1454 | 1.1244 | 64.86% |
| min2phase 데이터로 처음부터 학습 | 61.7초 | 3/6 | 2.8907 | 2.4285 | 26.13% |

CE는 선생이 선택한 행동의 교차 엔트로피로 작을수록 좋습니다. 학습한 epoch 중 검증 CE로만 모델을 선택했습니다. 테스트 결과로 선택하거나 추가 조정하지 않았습니다.

## 검증 및 한계

데이터 44,617행을 원래 경로에서 전부 재구성했고, 선생 해법 3,360개를 Java 구현으로 검증했습니다. 저장된 평가 행 300개 중 실제 해법 241개를 독립적으로 재검증했습니다. 실패 59건은 성공으로 대체하지 않았습니다. 가중치 해시와 CSV의 평균·성공 수가 요약과 일치합니다.

초기 파일럿입니다. 학습 큐브 3,000개·6 epoch·한 번의 학습만으로 처음부터 학습하는 방식의 잠재 성능을 판단할 수 없습니다. 초기화별 학습률과 BatchNorm 처리도 다릅니다. 실행 시간은 이 장비에서 관찰한 값이며 다른 작업의 영향을 받을 수 있습니다. 이전 실험의 양자화 모델 결과와 직접 섞어 비교하지 않습니다.

다음 실험은 학습 데이터를 더 확보하고, 검증용 큐브의 실제 빔서치 해결률로 모델을 고르는 것이 우선입니다. 쉬운 상태를 복습 데이터로 섞고, 선생의 여러 좋은 해법을 활용하는 방법도 비교할 수 있습니다. 이번 테스트 60개는 이미 확인했으므로 다음 최종 평가는 새로운 입력을 만들어 수행해야 합니다.
